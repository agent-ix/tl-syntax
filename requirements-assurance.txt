# The shared assurance lane (FR-006). Install this in its OWN environment.
#
# It is deliberately separate from the Draft 7 lane this repository's hosted CI
# installs (jsonschema 3.2.0, rfc3339-validator, rfc3986-validator), which is
# what the corpus gate and the retained PGM-01 schema checks were written
# against. engineering-assurance declares jsonschema>=4.23,<5. Both pins are
# correct for their own job and neither may be bent to fit the other, so they
# get one environment each:
#
#   make assurance-env  -> .venv-assurance, this file
#   pip install 'jsonschema==3.2.0' ...  (system/CI) -> the Draft 7 lane
#
# The pin is the accepted release from agent-ix/engineering-assurance#8, which
# publishes engineering-assurance as a source distribution: the git tag IS the
# released artifact. It is not a branch head and must not be replaced by one.
