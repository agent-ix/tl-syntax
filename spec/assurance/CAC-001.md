# tl-syntax structural validation contract

## Component Boundary

The component begins at checked value or document construction and ends at a
validated borrowed formula view. It does not establish whether a formula is true
on a trace.

## Required Behavior

Every returned formula has an in-range root, backward-only operands, and valid
temporal intervals. Every exchanged document carries supported version and
profile identities, and proposition maps remain unambiguous.

## Failure Handling

Malformed values return a specific deterministic error. Unsupported wire
strings fail deserialization. No rejection is converted to an empty formula,
default profile, or successful result.

## Controls

Checked constructors and document validators are the admission controls. CI
exercises positive, boundary, and malformed inputs. New version variants require
review and corpus updates.

## Replacement

A replacement must pass the same public tests and corpus, retain the no-std
borrowed boundary, and demonstrate compatible wire and error behavior.
