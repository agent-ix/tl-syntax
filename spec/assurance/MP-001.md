# tl-syntax v0.1 conformance evidence plan

## Decision Use

The evidence informs the human source-release decision. A passing measurement
does not itself approve, certify, accredit, or publish a release.

## Metric and Rule

The metric is the proportion of applicable obligations with a current passing
outcome. The existing all-obligations-must-pass rule is represented by `>= 1.0`;
failed, missing, skipped, invalid, and non-conclusive outcomes stay individually
visible and cannot contribute to the numerator. An empty applicable population
is invalid, not a perfect proportion. The v2 definition adds the numeric rule
and binds the protected measurement apparatus; v1 observations must not be
rejudged under v2. The expected outcomes originate in human-authored
requirements and fixtures, with independent mechanical checks where declared.

## Population

The population is the complete v0.1 requirement matrix, all public feature
configurations (`default`, `alloc`, `serde`, and all features), every unit and
integration test, all JSON corpus fixtures, formatting, clippy, license, unsafe-
comment, and documentation checks.
The population also includes every signal-domain variant, catalog and binding
invariant, requirement-context field, owned/borrowed conversion, legacy v1 wire
fixture, and feature-boundary combination introduced under issue #15.

## Collection Procedure

Run `make ci`, explicit feature checks, corpus verification, Quire validation,
code review, and gap analysis against one source revision. `make
assurance-inputs` is the only step that executes a producer; every other step
consumes the structured results it wrote. Retention belongs to Quoin: the
change-assurance record, one proof attestation per obligation over bytes a
producer already wrote, and the verification receipt. This repository operates
no collector, retains no evidence directory of its own, and content-addresses
nothing on its own authority. Retain the corpus manifest and fixtures in source
control.

## Interpretation

A zero exit status supports only the obligations exercised by that command.
Missing, skipped, or stale evidence is a gap. Human inspection remains required
for scope, dependency pins, rights, provenance, and the final source-release
decision.
